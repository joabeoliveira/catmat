Reposite de Joabe Oliveira. Stack: Next.js (App Router), TypeScript, Tailwind, shadcn/ui, Zustand, Prisma, PostgreSQL, Zod, Vitest.

Regras Cruciais:
1. Sempre siga a arquitetura modular em `src/features/`.
2. Antes de codificar uma tela ou API, crie ou verifique o arquivo `.types.ts` e `.schema.ts` do módulo correspondente.
3. Use apenas Tailwind CSS + shadcn/ui.
4. Escreva código estritamente tipado (TypeScript) sem uso de 'any'.
5. Código limpo focado em performance, pronto para deploy no Easypanel via Docker.
